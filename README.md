# MateTech ⚽

Sistema de gestión de ligas de fútbol con panel de administración, control de clubes y jugadores.

---

## 📋 Descripción

MateTech es una aplicación web desarrollada en PHP que permite administrar una liga de fútbol. Ofrece dos niveles de acceso: **Administrador**, con control total sobre usuarios, clubes y jugadores; y **Club**, con acceso a vistas de consulta de la liga.
